# デスクの余白。

デスク収納・配線整理の道具選びを紹介する日本語のアフィリエイトサイト。

- 公開予定・登録URL: https://desk-no-yohaku.pages.dev/
- 配信: Cloudflare Pages（実際の配信状態はCloudflare側で要確認）
- サイト本体: ルートの index.html / style.css / notes/ / sitemap.xml
- Amazonアソシエイトの登録URL: 利用者が登録済み（審査承認とは別）

## 運用上の注意

- Amazonアソシエイトのタグは既存ページで moon12-22 を使用。変更前に本人確認すること。
- 既存の21商品リンクはAmazon検索結果（/s?k=）へのリンク。個別商品ページへの変更には正しいASINの確認が必要。未確認のASIN、星評価、レビュー件数、価格を捏造しない。
- 商品画像はAmazon公式の利用条件を確認し、許可された方法で表示する。第三者の商品画像を無断転載しない。
- レビューを引用する場合はAmazonの規約、引用条件と最新性を確認する。
- 記事冒頭の「結論から」は禁止。比較・寸法・設置条件・注意点を具体的に記載する。
- 商品リンクはユーザー希望の「Amazonで評価を見る」を基本とするが、リンク先にレビューが存在することを確認する。
- sitemap.xmlとrobots.txtを記事追加時に更新し、公開後にリンク・モバイル表示・Search Consoleを確認する。

## 公開・登録チェック

1. Cloudflare Pagesのビルド・公開状況を確認する。
2. https://desk-no-yohaku.pages.dev/ と各記事、sitemap.xml、robots.txt のHTTP応答を確認する。
3. Amazonアソシエイト側に登録したURLが上記と一致するか確認する（登録作業は利用者が実施済み）。
4. 公開サイトに適切なアフィリエイト開示、プライバシーポリシー、問い合わせ先があるか確認する。
