## Amazonアソシエイト運用上の確認事項

- 既存記事のAmazonリンクにはトラッキングID moon12-22 が含まれています。
- 主要3記事の21商品リンクは検索結果URLです。個別商品ページへの差し替えには正確なASINの確認が必要です。未確認ASINを推測して設定しないでください。
- 商品画像、星評価、レビュー数はAmazonの利用規約に従い、利用が認められた手段で取得・表示してください。未確認の評価を捏造しないでください。
- Amazonアソシエイト管理画面の「ウェブサイトとモバイルアプリの変更」で公開URLを追加し、保存後に登録一覧を確認してください。GitHubへの変更だけではAmazon側への登録は完了しません。
